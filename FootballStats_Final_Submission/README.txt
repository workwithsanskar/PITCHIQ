FOOTBALL PLAYER STATISTICS - SUBMISSION PACKAGE

Files:
- FootballStats_Final.ipynb: reviewed Jupyter notebook with executed outputs.
- players_data_light-2025_2026.csv: dataset required by the notebook.

How to run:
1. Extract all files into the same folder.
2. Open FootballStats_Final.ipynb in Jupyter Notebook or JupyterLab.
3. Select Kernel > Restart Kernel and Run All Cells.

Note: The web-scraping section requires an internet connection. If the website cannot be reached, the notebook reports the issue and the data analysis still runs.
